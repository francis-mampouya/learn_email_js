Introduction

Qu'est-ce qu'EmailJS ?

Comprendre les fondations avant d'écrire la première ligne de code.

Qu'est-ce qu'EmailJS ?

EmailJS est un service tiers qui permet d'envoyer des emails directement depuis du JavaScript côté client, sans écrire la moindre ligne de code serveur.

À quoi ça sert ?

Formulaires de contact, newsletters, confirmations de commande, notifications : tout ce qui nécessite un envoi d'email depuis une page web.

Comment ça fonctionne ?

Vous configurez un service (ex. Gmail), un template (modèle d'email) sur le dashboard EmailJS, puis vous connectez votre formulaire via le SDK JavaScript.

Avantages & limites

Avantages : zéro backend, mise en place rapide, idéal pour apprendre et prototyper.

Limites : plan gratuit limité (≈ 200 emails/mois, 1 requête/sec), clé publique exposée, non adapté à très haut volume.

    Configuration

    Vos identifiants EmailJS

    Stockés uniquement dans votre navigateur (localStorage). Rien n'est envoyé sur un serveur tiers.

    Identifiants du laboratoire

    Ces valeurs servent uniquement à alimenter le formulaire de test ci-dessous.

    EmailJS → Account → General → Public Key
    Email Services → le nom de votre service (ex. service_xxxx)
    Email Templates → l'identifiant de votre modèle (ex. template_xxxx)

    Public vs. Secret

    La Public Key est faite pour être visible dans votre code JavaScript. Elle identifie simplement l'expéditeur.

    En revanche, avec EmailJS, aucune clé secrète n'est utilisée côté navigateur. Si on vous demande d'afficher un secret dans le front, arrêtez-vous immédiatement.

    Règle d'or : ne mettez jamais une clé privée côté client. Tout navigateur est visible par n'importe qui.

    Laboratoire

    Envoyez un vrai email

    Remplissez le formulaire et observez les états : chargement, succès, erreur.

    Comment ça marche ?

    1. Les champs possèdent un attribut name correspondant aux variables du template.
    2. Le SDK collecte automatiquement ces valeurs avec sendForm().
    3. Chaque champ est validé en JavaScript avant l'envoi.
    4. Le bouton reflète l'état : chargement / succès / erreur.

    Variables attendues dans votre template : from_name, reply_to, subject, message.

    Code source

    Exemple concret

    Le code réellement utilisé par ce laboratoire. Copiez-le et adaptez-le à votre projet.

    index.html 
    <!-- Formulaire HTML minimal -->
<form id="labForm">
  <input type="text"  name="from_name" placeholder="Nom" />
  <input type="email" name="reply_to"  placeholder="Email" />
  <input type="text"  name="subject"   placeholder="Sujet" />
  <textarea           name="message"   placeholder="Message"></textarea>
  <button type="submit">Envoyer</button>
</form>
    // Initialisation d'EmailJS avec la Public Key
emailjs.init({ publicKey: 'YOUR_PUBLIC_KEY' });

document.getElementById('labForm')
  .addEventListener('submit', async (e) => {
    e.preventDefault();

    try {
      const res = await emailjs.sendForm(
        'YOUR_SERVICE_ID',   // Service ID
        'YOUR_TEMPLATE_ID',  // Template ID
        '#labForm'
      );
      console.log('Email envoyé !', res.status, res.text);
    } catch (err) {
      console.error('Erreur :', err);
    }
  });
