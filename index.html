Introduction à EmailJS

❓

Qu'est-ce qu'EmailJS ?

EmailJS est un service qui te permet d'envoyer des emails directement depuis du JavaScript côté client. Tu n'as pas besoin de créer un backend (serveur).

🎯

À quoi ça sert ?

Envoyer des emails depuis un formulaire de contact, un panier, une newsletter… le tout en quelques lignes de JavaScript, directement depuis ta page web.

⚙️

Comment ça fonctionne ?

Tu configures un service (ex. Gmail), un template (modèle d'email) sur le site EmailJS, puis tu connectes ton formulaire via le SDK JavaScript.

⚖️

Avantages & limites

Avantages : zéro backend, mise en place rapide, idéal pour apprendre et prototyper.
Limites : base gratuite limitée en volume (≈ 200 emails/mois, 1 requête/sec), expose une clé publique, ne remplace pas une solution pro à très haut volume.

Configuration EmailJS

Identifiants du laboratoire

Renseigne tes identifiants — ils sont stockés uniquement dans ton navigateur (localStorage), jamais exposés publiquement ici.

À copier dans : EmailJS → Account → General → Public Key
Email Services → le nom de ton service (ex. service_xxxx)
Email Templates → l'identifiant de ton modèle (ex. template_xxxx)

⚠️ Public vs. Secret

La Public Key est faite pour être visible dans ton code JavaScript. C'est normal : elle identifie l'expéditeur.

En revanche tu ne disposes d'aucune clé secrète côté navigateur avec EmailJS. Si on te demande d'afficher un secret dans le front, arrête-toi.

Règle d'or : ne mets jamais une clé privée côté client. Un navigateur est visible par tous.

Laboratoire — envoie un vrai email

Remplis le formulaire et envoie le message via EmailJS. Observe les états : chargement, succès, erreur.

Comment ça marche ?

  1. Les champs ont un attribut name qui correspond aux variables du template.
  2. Le SDK collecte automatiquement ces valeurs avec sendForm().
  3. Chaque champ est validé en JavaScript avant l'envoi.
  4. Le bouton change d'état (chargement / succès / erreur).

Le template EmailJS doit contenir les variables : from_name, reply_to, subject, message.

Code exemple

Le code réellement utilisé par ce laboratoire. Copie-le et adapte-le à ton projet.

index.html 
<form id="labForm">
  <input type="text" name="from_name" />
  <input type="email" name="reply_to" />
  <input type="text" name="subject" />
  <textarea name="message"></textarea>
  <button type="submit">Envoyer le message</button>
</form>
// Initialise EmailJS avec ta clé publique
emailjs.init({
  publicKey: 'YOUR_PUBLIC_KEY',
});

document.getElementById('labForm')
  .addEventListener('submit', (e) => {
  e.preventDefault();

  emailjs.sendForm(
    'YOUR_SERVICE_ID', // Service ID
    'YOUR_TEMPLATE_ID', // Template ID
    '#labForm'
  ).then(() => {
    console.log('Email envoyé !');
  }, (error) => {
    console.error('Erreur :', error);
  });
});
